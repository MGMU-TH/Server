# OPSCORE — IT Operations Center

เว็บไซต์แดชบอร์ดสำหรับติดตามสถานะเครื่องแม่ข่าย เครือข่าย เหตุการณ์ และบันทึกการทำงาน

## ไฟล์ภายในโปรเจกต์

- `index.html` — โครงสร้างหน้าเว็บ
- `style.css` — รูปแบบหน้าจอและการรองรับอุปกรณ์
- `script.js` — การทำงานของระบบและข้อมูลภายในเบราว์เซอร์
- `audio.js` — ระบบเสียงสังเคราะห์ (พัดลม เสียงติ๊ก บี๊บ เสียงกด ไซเรน) ไม่ต้องใช้ไฟล์เสียง

## ความสามารถ

- Overview แสดงจำนวนเครื่องแม่ข่าย สถานะ และกิจกรรมล่าสุด
- Server Room แสดงเครื่องแม่ข่าย 3 ตู้ ตู้ละ 5 เครื่อง
- Restart Server สำหรับจัดการเหตุการณ์ที่ต้องเริ่มบริการใหม่
- Switch Connection สำหรับเปลี่ยนเส้นทางเครือข่าย
- Security Center สำหรับตรวจสอบเหตุการณ์ด้านความปลอดภัยและยืนยันรหัส 6 หลัก
- Incident Management แสดงเหตุการณ์ที่เปิดอยู่และรายการที่ดำเนินการแล้ว
- System Logs บันทึกกิจกรรมและส่งออกเป็นไฟล์ CSV
- ตั้งค่าเสียง (เปิด/ปิด ความดัง เสียงบรรยากาศ เสียงกด) และรูปแบบสีหน้าจอได้ เสียงเริ่มหลังกดหน้าจอครั้งแรก ตามข้อจำกัดของเบราว์เซอร์
- จดจำข้อมูลในเบราว์เซอร์ด้วย LocalStorage

## รูปแบบเหตุการณ์

ระบบจะสุ่มเหตุการณ์หนึ่งรายการทุก 60 วินาที โดยเลือกเครื่องแม่ข่ายที่ยังออนไลน์ก่อน แล้วจึงสุ่มประเภทเหตุการณ์ตามสัดส่วนที่กำหนดไว้ใน `script.js`

- เหตุการณ์ทั่วไป 80%: สุ่มเป็น Restart Server หรือ Switch Connection
- เหตุการณ์ด้านความปลอดภัย 20%: ต้องกด `DEFEND SYSTEM` และกรอกรหัส 6 หลักที่แสดงในหน้าต่างยืนยัน

ปรับสัดส่วนได้จากตัวแปร `NORMAL_EVENT_WEIGHT` และ `SPECIAL_EVENT_WEIGHT` ที่ด้านบนของ `script.js` โดยไม่จำเป็นต้องแก้ส่วนอื่น

## การนำขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้ง 5 ไฟล์นี้ไว้ที่ Root ของ Repository
3. เข้า `Settings` → `Pages`
4. ในหัวข้อ Build and deployment เลือก `Deploy from a branch`
5. เลือก Branch `main` และ Folder `/ (root)` แล้วกด Save
6. เมื่อ GitHub Pages เผยแพร่เว็บไซต์แล้ว ให้นำโดเมนของคุณไปตั้งค่าในช่อง Custom domain
7. ตั้งค่า DNS ของโดเมนตามค่าที่ GitHub Pages แสดง และเปิด Enforce HTTPS เมื่อพร้อมใช้งาน

## ข้อมูลและข้อจำกัด

- เป็นเว็บไซต์ Static ใช้ HTML, CSS และ JavaScript ไม่ต้องติดตั้ง Backend
- ข้อมูลถูกเก็บไว้ใน LocalStorage ของเบราว์เซอร์และอุปกรณ์นั้น ๆ
- ข้อมูลจะไม่ซิงก์ข้ามอุปกรณ์หรือข้ามเบราว์เซอร์โดยอัตโนมัติ
- การสุ่มเหตุการณ์ทำงานขณะที่หน้าเว็บไซต์เปิดอยู่เท่านั้น
- ปุ่ม Restart และ Switch Connection เปลี่ยนสถานะภายในหน้าเว็บ ไม่ได้สั่งงานเครื่องแม่ข่ายหรือเปลี่ยนเครือข่ายจริง
- ไม่มีการเชื่อมต่อระบบเครือข่ายภายนอกเพื่อดำเนินการกับเซิร์ฟเวอร์
